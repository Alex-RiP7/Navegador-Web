# Navegador-Web

Simulador sencillo de un navegador web que usa una **estructura de datos tipo pila (LIFO)**.

El último elemento registrado es el primero en recuperarse.

## Opciones del menú

1. Visitar una página web  
2. Regresar a la página anterior  
3. Mostrar la página actual  
4. Mostrar el historial de las páginas visitadas en orden descendente  
5. Verificar si el historial está vacío o eliminarlo  
6. Salir del programa  

## Archivos

- `navegador.py` → Versión de consola en Python  
- `index.html` → Versión web (se abre directamente en el navegador)

## Cómo usar

### Versión Python (consola)
```bash
python navegador.py
```

### Versión HTML
Abre el archivo `index.html` en cualquier navegador.
